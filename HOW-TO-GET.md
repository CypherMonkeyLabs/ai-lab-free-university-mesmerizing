# How to get the course

No login. No API key to open the file. MIT license. No warranty.

## Download

1. Get [v2-UNIVERSITY.html.zip](zips/v2-UNIVERSITY.html.zip), or the [direct GitHub link](https://github.com/cipher0x9/ai-lab-free-university-mesmerizing/raw/main/zips/v2-UNIVERSITY.html.zip).
2. Unzip it.
3. Open `v2-UNIVERSITY.html` in Chrome, Safari, Edge, or Firefox.

The same file is in the repository at [university/v2-UNIVERSITY.html](university/v2-UNIVERSITY.html).

`university/v1-SLICE.html` is an older short page. Use v2.

## Phone

Use the full Chrome or Safari app. In-app browsers often refuse a local HTML file.

On iPhone: download the file, then open it from the Files app in Chrome or Safari. The first open can take a moment.

## Clone

```bash
git clone https://github.com/cipher0x9/ai-lab-free-university-mesmerizing.git
cd ai-lab-free-university-mesmerizing
```

Then open `university/v2-UNIVERSITY.html`.

## Printing

Any lesson can be printed from the browser. Print uses the lesson text rather than the sidebar.

Free to use, share and remix. See [START-HERE.md](START-HERE.md) for how to study.
