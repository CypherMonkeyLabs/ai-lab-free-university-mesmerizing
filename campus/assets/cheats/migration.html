Migration and cutover

One page. Print from the browser if you want paper. The PDF beside this file is the same text.

  1. Inventory the old bot's answers and their allowed sources.
  2. Write ten tasks, including a refusal.
  3. Shadow mode: users still see the old bot.
  4. Limited audience, kill switch tested, then a wider cut.
  5. Retire the old bot only after its tasks stay in the eval set.
