Ports and protocols

One page. Print from the browser if you want paper. The PDF beside this file is the same text.

  1. Study matrix. Confirm every listener on the host you run.
  2. 443 TCP — HTTPS to a model API. Confirm the vendor host.
  3. 53 UDP/TCP — DNS.
  4. 4317 TCP — OTLP gRPC. OpenTelemetry default. Not re-fetched 2026-10-15.
  5. 4318 TCP — OTLP HTTP. OpenTelemetry default. Not re-fetched 2026-10-15.
  6. 11434 TCP — Ollama's published loopback default. Not re-fetched 2026-10-15.
  7. 5060 UDP/TCP — SIP, RFC 3261. Confirm the listener.
  8. 5061 TCP — SIP over TLS, commonly assigned. Confirm in the IANA registry.
  9. RTP — a range you configure, not one universal port.
  10. MCP stdio — no port. Remote MCP is HTTP on a port you choose.
  11. Sources: RFC 3261, OpenTelemetry OTLP spec, MCP specification 2025-06-18, Ollama docs, IANA service names.
