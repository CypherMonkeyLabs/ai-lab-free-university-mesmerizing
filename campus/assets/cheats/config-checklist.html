Configuration checklist

One page. Print from the browser if you want paper. The PDF beside this file is the same text.

  1. Pin the model id and the embedding id.
  2. Keep the key out of the repository.
  3. Bind a local runner to loopback until you mean to share it.
  4. Set a timeout and a retry cap that cannot double-send.
  5. Log ids and counts. Drop the key and the raw private text.
  6. Name the kill switch and the old path.
