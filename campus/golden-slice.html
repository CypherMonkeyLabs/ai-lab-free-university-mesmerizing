Mentor honesty

If Ollama is not installed, labs use a mock local brain. That still trains RTMA. Do not pretend it is a real model. Install later: ollama.com → ollama pull a current small instruct tag (example: llama3.2:3b, if the official library still lists it)

Labs 01–03 (mechanisms)

Lab 01 — Local model hello

UC analogy: dial your own lab phone and confirm the media path. If the stack is down, document the failure — still useful.

  • Probe http://127.0.0.1:11434
  • Generate a short RTMA explanation
  • Artifact under labs/artifacts/

Lab 02 — Tool call

UC analogy: CTI connector — do not invent agent state; call the contract and log the transaction.

  • Tool specs with JSON schema
  • Safe calculator (exact math)
  • Local glossary (RTMA, token, SIP…)
  • Synthesis grounded in tool results only

Lab 03 — Golden-10 eval

UC analogy: dial-plan regression pack — fixed cases, expected outcomes, pass/fail counters.

  • Suite file: labs/evals/golden10.json
  • Report: labs/reports/golden10-report.md
  • Threshold: 80%

Safety & free-share rules

Never in repo

  • API keys / .env
  • Customer data / PCAPs with PII
  • Private chats
  • Model weight blobs

Autonomy limits

  • No auto-email / auto-post
  • Human approval for external actions
  • Tools default least privilege

Size discipline

  • Default HTML ≤ 10–20 MB
  • Depth in markdown modules
  • Huge archives optional + labeled

UC pack

  • Never delete UC free share
  • Sibling, not replacement
  • Voice stays in the UC campus

Next-level engineering runway
