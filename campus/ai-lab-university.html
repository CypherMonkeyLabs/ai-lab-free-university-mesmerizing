Later tracks only work if you can keep proof and follow one safety rule.6 lessons01How models workExplain tokens, context, sampling, hallucination, and the model families named in current job posts.Why it matters. Token, context, and sampling mistakes cause more bad product calls than a weak slogan.8 lessons02PromptingWrite prompts as jobs with a done-check, an output shape, and a test for the next change.Why it matters. A prompt without a done-check cannot be improved, because nobody can say it failed.7 lessons03Local modelsRun an open-weight model on your own machine, pick a size that fits, and keep data separate from weights.Why it matters. A local model is how you keep data off a hosted service and learn the real memory limit.7 lessons04APIs and costCall a hosted model without leaking the key, and read a bill in tokens, cache, and retries.Why it matters. A leaked key or an unread bill ends a project faster than a clumsy prompt.6 lessons05RetrievalBuild a retrieval pipeline that cites sources, and measure whether the right passage was found.Why it matters. An answer is grounded only when it cites a passage you actually retrieved.7 lessons06AgentsDesign a tool loop with a schema, a permission boundary, a step cap, and a trace.Why it matters. A tool loop without a schema and a step cap spends money and takes actions you did not allow.7 lessons07MCPExplain the Model Context Protocol and connect tools without granting a server silent access.Why it matters. A shared tool protocol helps only when the server cannot act without the permission you granted.6 lessons08Coding agentsReview an agent that edits a repository: plan, diff, tests, and a human gate.Why it matters. A repository edit is finished when the diff and the tests agree with the task.6 lessons09EvalsScore quality, safety, latency, and cost on a versioned task set before you trust a change.Why it matters. A change that feels better can still lose on quality, safety, latency, or cost.7 lessons10Fine-tuningDecide when LoRA is the right next step, and compare an adapter to the base model on the same tasks.Why it matters. LoRA is warranted when the same eval says prompting and retrieval already failed.5 lessons11SafetyWrite a personal policy for data, tools, and the actions that always need a person.Why it matters. The actions that need a person have to be written down before a tool can take them.5 lessons12Product skillsSpecify an AI feature the way a product manager and an engineer can build and measure together.Why it matters. A feature ships when one spec is measurable by both the product owner and the engineer.6 lessons13CapstoneFinish a small grounded assistant with citations, one tool, ten eval tasks, and a safety note.Why it matters. The course ends with a small assistant you can test, not a pile of notes.5 lessons

    Primary sources

    The course is a teaching text. These are the papers and specs behind the mechanisms.

    • Vaswani et al., 2017. Attention Is All You Need.

      Transformer attention, the mechanism behind the token playground.

      arXiv 1706.03762DOI
    • Lewis et al., 2020. Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks.

      Retrieve a passage, then generate. The retrieval track follows that split.

      arXiv 2005.11401DOI
    • Hu et al., 2021. LoRA: Low-Rank Adaptation of Large Language Models.

      Low-rank updates instead of full fine-tuning. The rank lab is a picture of that budget.

      arXiv 2106.09685DOI
