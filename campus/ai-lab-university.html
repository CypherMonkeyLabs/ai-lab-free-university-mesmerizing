00Start hereLearn how this course works, what to save as proof, and the safety rules that apply everywhere else.Why it matters. Later tracks only work if you can keep proof and follow one safety rule.6 lessons01How models workExplain tokens, context, sampling, hallucination, and the model families named in current job posts.Why it matters. Token, context, and sampling mistakes cause more bad product calls than a weak slogan.10 lessons02PromptingWrite prompts as jobs with a done-check, an output shape, and a test for the next change.Why it matters. A prompt without a done-check cannot be improved, because nobody can say it failed.10 lessons03Local modelsRun an open-weight model on your own machine, pick a size that fits, and keep data separate from weights.Why it matters. A local model is how you keep data off a hosted service and learn the real memory limit.7 lessons04APIs and costCall a hosted model without leaking the key, and read a bill in tokens, cache, and retries.Why it matters. A leaked key or an unread bill ends a project faster than a clumsy prompt.7 lessons05RetrievalBuild a retrieval pipeline that cites sources, and measure whether the right passage was found.Why it matters. An answer is grounded only when it cites a passage you actually retrieved.9 lessons06AgentsDesign a tool loop with a schema, a permission boundary, a step cap, and a trace.Why it matters. A tool loop without a schema and a step cap spends money and takes actions you did not allow.9 lessons07MCPExplain the Model Context Protocol and connect tools without granting a server silent access.Why it matters. A shared tool protocol helps only when the server cannot act without the permission you granted.6 lessons08Coding agentsReview an agent that edits a repository: plan, diff, tests, and a human gate.Why it matters. A repository edit is finished when the diff and the tests agree with the task.6 lessons09EvalsScore quality, safety, latency, and cost on a versioned task set before you trust a change.Why it matters. A change that feels better can still lose on quality, safety, latency, or cost.9 lessons10Fine-tuningDecide when LoRA is the right next step, and compare an adapter to the base model on the same tasks.Why it matters. LoRA is warranted when the same eval says prompting and retrieval already failed.6 lessons11SafetyWrite a personal policy for data, tools, and the actions that always need a person.Why it matters. The actions that need a person have to be written down before a tool can take them.6 lessons12Product skillsSpecify an AI feature the way a product manager and an engineer can build and measure together.Why it matters. A feature ships when one spec is measurable by both the product owner and the engineer.6 lessons13CapstoneFinish a small grounded assistant with citations, one tool, ten eval tasks, and a safety note.Why it matters. The course ends with a small assistant you can test, not a pile of notes.5 lessons14Contact centerPlace a voice model beside the queue, the recording, and the human who still owns the call.Why it matters. A voice model that owns the queue will mishandle emergency calls and the recording.5 lessonsEXEcosystemMap sister systems, ports, cutovers, and the claims this course will not certify.Why it matters. Ports, cutovers, and sister systems are how a demo becomes a system you can operate.12 lessons

Marks

    Choose a route

    Short paths through the same lessons. The track map is the full course.

    New to AI

    Enough mechanism to stop treating the model as a search box.

    1. How to use this campus
    2. A model predicts the next token
    3. The context window is one shared budget
    4. Hallucination is fluent text without evidence
    5. Write the job, the input, and the done-check
    6. Run a model locally when the data should stay put

    Grounded assistant

    Retrieve, cite, call one tool, and prove the answers.

    1. Retrieve when the answer has to come from a source
    2. Failure modes to test before you tune the prompt
    3. An agent is a loop with a stop rule
    4. An eval is a versioned test, not a feeling
    5. Start with ten tasks you can explain
    6. Choose a capstone you can finish on your own notes

    Coding agent work

    The loop teams expect when a job post says coding agent or MCP.

    1. A coding agent edits a repository under rules
    2. Review the diff and the tests
    3. MCP connects a model to tools you did not hard-code
    4. Consent, authentication, and untrusted servers
    5. A person approves sends, payments, and deletes
    6. Gate changes to the prompt, the model, and the index

    Product and PM

    Spec, metrics, failure states, and the build-or-buy choice.

    1. Name the job before you name the model
    2. Write a one-page spec
    3. Share four numbers with engineering
    4. Design the empty, slow, wrong, and unsafe states
    5. Fine-tune only after a measured failure of the cheaper fixes
    6. How do you decide to fine-tune?

    Voice agent bridge

    The model sits beside the phone system. It does not own the call.

    1. Contact center voice AI: the ASR, TTS, and LLM loop
    2. AI agents in the contact center
    3. AI in the contact center ecosystem
    4. Voice bridge: SIP, PSTN, recording, WFM, and emergency calls
    5. AI agents beside a human queue
    6. Add voice only when latency and handoff are designed

    Primary sources

    The course is a teaching text. These are the papers and specs behind the mechanisms.

    • Vaswani et al., 2017. Attention Is All You Need.

      Transformer attention, the mechanism behind the token playground.

      arXiv 1706.03762DOI
    • Lewis et al., 2020. Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks.

      Retrieve a passage, then generate. The retrieval track follows that split.

      arXiv 2005.11401DOI
    • Hu et al., 2021. LoRA: Low-Rank Adaptation of Large Language Models.

      Low-rank updates instead of full fine-tuning. The rank lab is a picture of that budget.

      arXiv 2106.09685DOI
    • Model Context Protocol specification, revision 2025-06-18.

      JSON-RPC handshake, tools/list, and tools/call. The inspector plays a teaching trace of that shape.
