## Who this is for

You belong here as a student, career-changer, engineer, founder, teacher, creator, researcher, or domain expert. No prior AI job, paid account, or powerful computer is required to begin.

Pick one real problem from your world. Learn the mechanism in plain language, run the smallest safe experiment, measure it, keep the artifact, and teach it back.

- Keep private data local until a measured need crosses a boundary.
- Compare a local model and a hosted API on the same task.
- Treat every agent as a bounded workflow with typed tools and a visible stop.
- Run an eval before you trust a prompt, a model, a retrieval index, or a release.
- Keep RTMA evidence so the learning can move with you.
