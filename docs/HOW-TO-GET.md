# How to get the course

No login. No API key to open the file. MIT license. No warranty.

## Download

1. Get [ai-lab-university.html.zip](../downloads/ai-lab-university.html.zip), or the [direct GitHub link](https://github.com/cipher0x9/ai-lab-free-university-mesmerizing/raw/main/downloads/ai-lab-university.html.zip).
2. Unzip it.
3. Open `ai-lab-university.html` in Chrome, Safari, Edge, or Firefox.

The same file is in the repository at [campus/ai-lab-university.html](../campus/ai-lab-university.html). The short starter is [golden-slice.html.zip](../downloads/golden-slice.html.zip).

## Phone

Use the full Chrome or Safari app. In-app browsers often refuse a local HTML file.

On iPhone: download the file, then open it from the Files app in Chrome or Safari. The first open can take a moment.

## Clone

```bash
git clone https://github.com/cipher0x9/ai-lab-free-university-mesmerizing.git
cd ai-lab-free-university-mesmerizing
```

Then open `campus/ai-lab-university.html`.

## Printing

Any lesson can be printed from the browser. Print uses the lesson text rather than the sidebar.

Free to use, share and remix. See [START-HERE.md](./START-HERE.md) for how to study, and [HOW-TO-USE.md](./HOW-TO-USE.md) for a 30-day plan.
