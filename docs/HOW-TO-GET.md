# How to get the campus

No login for the download. No API key to open the HTML. Educational only. MIT. No warranty.

## Recommended

1. Download [ai-lab-university.html.zip](../downloads/ai-lab-university.html.zip).
2. Unzip.
3. Open **`ai-lab-university.html`** in Chrome, Safari, Edge, or Firefox.

Short starter: [golden-slice.html.zip](../downloads/golden-slice.html.zip).

## Phone

- Use the full Chrome or Safari app.
- Avoid in-app browsers inside mail, chat, and social apps.
- iPhone: download, then Files, then open the HTML in the browser.
- The first load can take a few seconds.

## Clone

```bash
git clone https://github.com/cipher0x9/ai-lab-free-university-mesmerizing.git
cd ai-lab-free-university-mesmerizing
python3 labs/01-local-hello.py
```

Then open `campus/ai-lab-university.html`.
