# Lab kit

These parts are the reusable chrome for this learning lab.

| Piece | Role |
|---|---|
| `assets/css/frame.css` | Drawer, banner, and display controls adapted from the Webex lab kit |
| `assets/css/wow.css` | Phone dock and tour spots from that kit |
| `assets/css/footer.css` | Boxed disclaimer and glowing brand row |
| `assets/css/lab.css` | Bright theme, contrast, and the non-sticky banner |
| `assets/js/frame.js` | Menu, banner arrows, font size, and font colour |
| `assets/js/university.js` | Quizzes, play widgets, and the service worker |
| `guide/guide.js` | Monkey guide, centre greeting, phone sheet, read-along |
| `guide/guide.css` | Crisp monkey and themed controls |
| `scripts/build_lab.py` | Pages, drawings, and downloads |
| `scripts/verify.mjs` | Brand links, counts, and PNG pairs |
| `scripts/gzip-static.mjs` | Gzip static server used for measurement |

The older campus shell under `campus/` is prior study notes. It is not this kit.
