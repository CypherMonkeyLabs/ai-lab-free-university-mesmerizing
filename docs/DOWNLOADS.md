# Downloads

The course is [campus/ai-lab-university.html](../campus/ai-lab-university.html): 15 tracks, **581 lessons**, one offline page. The zip also carries the audio folder. Leave that folder beside the HTML.

Free for learning. Educational only. MIT. No warranty.

| What | Where | How |
|---|---|---|

**Open** in Chrome, Safari, Edge, or Firefox (the full browser). Any lesson can be saved with Print → Save as PDF.

GitHub also serves the zip at [this raw URL](https://github.com/cipher0x9/ai-lab-free-university-mesmerizing/raw/main/downloads/ai-lab-university.html.zip) once it is on the default branch.

## Phone and desktop

- Desktop is the best place to study.
- Phone: full Chrome or Safari only, not an in-app browser.
- No API key is required to open the HTML.

Steps: [HOW-TO-GET.md](./HOW-TO-GET.md) · How to study: [HOW-TO-USE.md](./HOW-TO-USE.md)
