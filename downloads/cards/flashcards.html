T1-R1

Artifact

A file the run wrote, so the result is not only a memory.

T1-R2

Pure function

Same input, same output, no hidden write.

T1-R3

Status code

The number HTTP uses to say how the request finished.

T1-R4

Secret

A value that grants access. It is not lesson content.

T1-R5

Golden set

Questions with agreed answers, reused so scores compare.

T1-R6

Token

The piece of text a given model reads or emits.

T2-R1

Grounding

Tying a claim to a passage you can open.

T2-R2

Context window

The maximum text one model call considers.

T2-R3

Temperature

A sampling control. It is not a truth dial.

T2-R4

Refusal

Stopping instead of filling a gap with a guess.

T2-R5

Model card

The provider's note of intended use and limits. Confirm it is current.

T2-R6

Done check

The condition that says the output is finished enough.

T3-R1

Role

The label that says whether a line is an instruction, a person, or a tool.

T3-R2

Schema

The declared shape of an output or a tool argument.

T3-R3

Regression

A check that used to pass and now fails.

T3-R4

p95

A point on the slow tail: about 95 of 100 samples are faster.

T3-R5

Diff

The lines that changed between two versions.

T3-R6

Passage

A chunk of source text the answer may use.

T4-R1

Chunk

The unit you index and later paste into a call.

T4-R2

Embedding

A numeric vector standing in for a piece of text.

T4-R3

Candidate

A passage the search thought might help. It is not yet the answer.

T4-R4

Citation

A pointer to a passage you actually retrieved.

T4-R5

Ablation

Turning one piece off to see what changes.

T4-R6

Workflow

Steps in an order you wrote down.

T5-R1

Tool

A function the loop may call, with a schema and a known effect.

T5-R2

Trace

The ordered record of what the loop did.

T5-R3

Approval

A recorded human decision before an undo-hard action.

T5-R4

ReAct

A pattern that writes a reason and takes an action in turns.

T5-R5

Simplest design

The fewest moving parts that meet the done check.

T5-R6

MCP

Model Context Protocol, a public way for hosts to use tool servers.

T6-R1

Host

The application a person is actually using.

T6-R2

Resource

Data a server can expose without necessarily changing the outside world.

T6-R3

Transport

How the bytes of the protocol move.

T6-R4

Root

A boundary on files or data a server may see. Confirm the spec's word.

T6-R5

Paper server

A design you can trace without running a public service.

T6-R6

Channel

A way a person and the assistant exchange a turn: voice, chat, or message.

T7-R1

Barge-in

The person starts speaking while the assistant is still talking.

T7-R2

SLA

A service promise. This lab does not state one.

T7-R3

Wording

The channel-specific sentence. The policy stays put.

T7-R4

Handoff packet

The note a person needs in order to continue without guessing.

T7-R5

Learning lab

Study material. Not a job claim and not a product.

T7-R6

Serving

Answering calls with a model that is already trained.

T8-R1

Confirm before relying

The mark this lab uses when a public figure was not re-checked today.

T8-R2

Endpoint

The address of a hosted model API. Confirm it before you call it.

T8-R3

Allowed corpus

Text you have a right to put in the lab.

T8-R4

Policy page

The short rules the capstone is graded against.

T8-R5

Portfolio

The files a later reader can check. Not a title.
