Glossary card

One page. Print from the browser if you want paper. The PDF beside this file is the same text.

  1. Token: a chunk the model reads or writes. Not always a word.
  2. Context window: one budget shared by instructions, sources, and the answer.
  3. Retrieval: find a span, then generate. Cite the id.
  4. Tool schema: name, arguments, and your handler.
  5. Eval gate: quality, safety, latency, cost.
  6. The full glossary is the Glossary track in the campus.
